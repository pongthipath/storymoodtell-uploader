ใครใช้แอปนี้ / Who uses this app

storymoodtell uploader เป็นเครื่องมือส่วนตัวที่เจ้าของช่องใช้กับบัญชี YouTube ของตัวเองเท่านั้น ไม่เปิดให้บุคคลอื่นใช้

storymoodtell uploader is a personal tool used only by the channel owner with their own YouTube accounts. It is not offered to anyone else.

ข้อมูลที่เข้าถึง / Data accessed

แอปขอสิทธิ์ YouTube 2 อย่าง: อัปโหลดวิดีโอ (youtube.upload) และอ่านชื่อ/รหัสช่องเพื่อยืนยันว่าอัปเข้าช่องที่ถูกต้อง (youtube.readonly) แอปไม่อ่านอีเมล รายชื่อติดต่อ หรือข้อมูลอื่นในบัญชี Google

The app requests two YouTube permissions: uploading videos (youtube.upload) and reading the channel name and ID to confirm uploads go to the correct channel (youtube.readonly). It does not access email, contacts, or any other Google account data.

การเก็บและแบ่งปันข้อมูล / Storage and sharing

token การเข้าถึงเก็บไว้ในเครื่องคอมพิวเตอร์ของเจ้าของเท่านั้น ไม่ส่งไปเซิร์ฟเวอร์อื่น ไม่ขาย ไม่แบ่งปันข้อมูลกับบุคคลที่สาม และไม่ใช้เพื่อโฆษณา

Access tokens are stored only on the owner's own computer. No data is sent to other servers, sold, shared with third parties, or used for advertising.

การใช้ข้อมูลที่ได้จาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use · Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

การถอนสิทธิ์ / Revoking access

ถอนสิทธิ์ได้ทุกเมื่อที่ myaccount.google.com/permissions · Access can be revoked at any time at myaccount.google.com/permissions.
